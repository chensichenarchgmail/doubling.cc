空间的结构和序列中的身体、时间与差异，关于 Luigi Moretti

结构解决“空间彼此是什么关系”，序列解决“这些关系怎样发生”：建筑在身体的运动、延迟与回溯中逐步成为现实。

Luigi Moretti 空间结构 空间序列 身体经验 建筑时间 空间差异 La Rotonda 圣彼得大教堂

序

Luigi Moretti 在《Strutture e sequenze di spazi》中提出的问题，并不只是“建筑内部空间是什么形状”，其更根本的问题是：怎样把一个作为整体结构同时存在的建筑，转化为一个必须通过身体、时间和差异逐步显现的建筑。

换句话说，结构解决“空间彼此是什么关系”，序列解决“这些关系怎样发生”。

这一差异看似细微，却可以改变理解建筑空间的基本方式。建筑不再只是由房间构成的静态整体，也不只是供人穿越的一条流线；它开始成为一种在身体运动中逐渐展开的关系体系。空间之间原本已经存在的尺度、形状、光线和边界关系，必须经过进入、转向、压缩、延迟和到达，才真正转化成建筑经验。

一、从建筑实体到空间结构

Moretti 的第一个操作，是主动地削弱建筑的复杂性。在文章开头，他明确承认建筑同时通过明暗、构造肌理、材料、色彩、塑性、内部空间等多个方面存在，任何单一因素实际上都无法与其他因素彻底分离。但为了分析，他暂时把内部空间抽取出来，使原本不可见的“空”获得实体形态。由墙面包围的内部空间被理解为一种负的模具，墙体、柱子和外部实体退到背景，空间本身第一次成为可以被比较的对象。

这一操作的力量，在于它把原本只能逐步经历的建筑空间转化成了一个可以同时观看的整体。真实建筑要求身体经历“进入—通过—转向—到达”的时间过程，而空间模型却取消了这一过程。不同房间的内部体量被同时放置在观察者眼前，原本隐藏在墙体之后的关系一次性暴露出来。建筑因此从一个必须“走进去”的东西，暂时变成一个可以“从外面看完”的结构。

这种转换实际上完成了一次去时间化。结构首先是一种共时关系：一个空间的意义并不完全来自它自身，而来自它与其他空间所形成的差异网络。类似地，一个局部之所以取得自身的位置，并不是由于它孤立地拥有某种绝对属性，而是因为它处在一组横向差异的整体之中。

Moretti 的空间模型真正暴露的不是一个个孤立房间，而是 A 与 B 有何不同，B 与 C 有何不同，C 在整个空间系统中占据什么位置。这时，建筑首先呈现为空间结构。

二、从“空间是什么”到“空间怎样改变”

Moretti 随后为内部空间提出四个重要属性：几何形式、绝对体积、光的密度以及空间的“压力”或能量强度。

前两者相对容易成为稳定的对象属性。一个房间可以有确定的形状，也可以计算面积、高度和体积，但光的密度已经开始依赖位置，而所谓“压力”则更加明显地指向空间边界与身体之间的关系。墙离身体多近，顶棚如何下降，门洞怎样收紧，巨大的实体怎样逼近，都会改变空间被经验的方式。

因此，空间不能只写成“几何+体积”，它至少还包含光与边界在其中形成的场。但真正使 Moretti 的文章发生转折的，并不是四项参数本身，而是他随后开始比较这些参数如何从一个空间变化到另一个空间。

此时，设计问题不再只是“这个房间有多大”，而变成“下一个房间比这个房间大多少”。这意味着分析对象从空间状态转向了空间差值。

如果把连续空间写成 A—B—C—D，那么建筑经验真正敏感的并不是简单的 A+B+C+D，而是 ΔAB+ΔBC+ΔCD（注：Δ 表示差值）。也就是说，一个空间的意义只有在进入下一个空间以后才逐渐成立。

1. Palazzo Ducale Urbino：真正被组织的是变化，而不是房间

Moretti 对 Urbino 公爵宫的研究最清楚地说明了这一点。他把连续房间的长、宽、高和体积关系进行比较，又将空间转化为一系列可以彼此衡量的体量，以此观察连续空间如何逐渐扩大，并形成类似音乐“渐强”的效果。

假设连续空间的体量是 20—30—50—80。真正构成序列的并不是 20、30、50、80 这四个数字自身，而是差值 +10—+20—+30。这里已经产生了第二层关系：第一层是空间 V₁、V₂、V₃、V₄，第二层则是变化 ΔV₁、ΔV₂、ΔV₃。

如果这些差值本身继续扩大，那么建筑经验中便会出现一种“加速”：小幅展开—更大展开—突然展开。因此，这种经验并不只是“空间越来越大”，而是变化本身也越来越强。建筑由此开始具有节律。

传统比例往往研究一个对象内部的关系，比如长与宽、宽与高。而这里出现了另一种比例：前一个空间与后一个空间之间的比例，一种从“对象内部的秩序”变成了“对象之间的变化”的比例。

这也是为什么同样一个 10 米见方的大厅，在不同建筑中可以成为完全不同的空间事件：如果此前是 2 米宽的空间，它意味着释放；如果此前是 20 米宽的空间，它反而可能意味着收缩。因此，“大”“小”“开放”“压迫”都不再是孤立空间绝对拥有的属性，而是关系。

三、身体如何使序列从结构中发生

当这一点被推进到极致，Moretti 的问题就不再只是几何分析，因为真实建筑中的空间差异，必须由一个运动着的身体来经历。

如果没有身体，A、B、C、D 只是一套同时存在的空间状态。只有当身体从 A 进入 B，再从 B 进入 C 时，差异才获得时间。这时空间经验可以被写成：身体在 A 中—穿过门槛—进入 B—转向—看见 C—向 C 运动。

这里最重要的变化是：空间不再只是一个等待被观察的客体，而成为一个与行动发生联系的场。身体首先不是一个几何学中的点，它能够前进、转身、伸展、上升、停留，也能够被墙体逼迫、被开口吸引、被视线诱导。因此，一个门洞首先不是“墙上的矩形开口”，而是“我能够从这里通过”；一道楼梯不仅是一组踏步，也是“我能够上升”；一条狭长走廊不仅拥有宽度和长度，它同时迫使身体获得方向。

身体对于世界的把握不是先拥有完整表象，再决定是否行动。身体本身就在行动中取得世界，空间也在这种行动能力中显露。梅洛庞蒂把这种关系概括为从 “I act” 走向 “I can”，即主体首先通过行动能力进入世界，而不是作为纯粹旁观者站在世界之外。

这恰好可以帮助我们重新理解 Moretti 所谓的空间“压力”。压力并不是像长度、面积一样储存在房间内部的物理量，它发生在身体与边界之间。因此，比起说“这是一个压迫的房间”，更准确的问题应该是：这个空间是如何在身体移动过程中变得压迫的？

2. La Rotonda：压缩和释放不是空间，而是事件

Palladio 的 La Rotonda 是 Moretti 方法最清楚的例子之一。从平面结构上看，它具有高度稳定的中心性与对称性：四个方向围绕中央大厅展开，整体几何秩序近乎静止。

但身体并不以这种方式经验它。真实的进入序列是：portico—andito—central hall，从门廊进入狭长过渡空间，再抵达中央大厅，空间经历开放、收缩和重新展开。

因此，“压缩”并不属于 andito 自身。如果一个人从更狭窄的空间进入它，它未必构成压缩。它之所以成为压缩，是因为身体刚刚经历了更开放的空间。同样，中央大厅之所以成为释放，也不是简单因为它很大，而是因为身体刚刚穿过了一个受限、狭窄、压力更高的过渡状态。

于是，“开放—压缩—释放”不是三个空间的标签，而是一串事件。这里出现了一个决定性的区别：空间不是名词性的状态，而开始成为动词性的变化。

建筑师设计的不再只是“大厅”“走廊”“门厅”，而是展开、收缩、阻碍、转向、显露、释放。这时，structure 与 sequence 的区别已经非常清楚：结构告诉我们三个空间彼此相连，序列告诉我们开放如何变成压缩，压缩又如何变成释放。

四、序列不是流线，而是时间结构

因此，必须把 sequence 与 circulation 区分开。

流线回答的是：“我怎样从 A 走到 B？”序列回答的是：“从 A 到 B，我与整个空间的关系发生了什么变化？”

一条非常顺畅的流线完全可能没有真正的空间序列。A—B—C—D，如果每一个空间的高度、体量、亮度、边界压力乃至方向关系都近乎不变，那么身体虽然不断前进，空间经验却可能几乎静止。相反，一个很短的路径也可以拥有极强序列：开阔—收缩—转向—延迟—突然展开。

所以 Moretti 真正研究的不是运动路线本身，而是运动过程中空间状态的不均匀变化。从这个意义上说，序列可以理解为：空间结构被身体时间化的过程。

3. 后一个空间会重新解释前一个空间

一旦空间必须在时间中展开，那么空间的意义就无法在第一次遇见身体时完成。

一个人在狭窄走廊中时，它可能仅仅被经验为昏暗、逼仄、受限。但当巨大大厅最终出现以后，刚才那段走廊会被重新理解：原来它不仅仅是狭窄，它还是到达大厅以前的压缩。

后来的空间因此反过来改变了此前空间的意义。

这与把事物理解为动态“环节”而非固定实体的思路相通：一个环节不能依靠自身获得完整规定，它只有进入后续运动、与其他环节发生关系以后，其位置才逐渐清楚。它们必须在动态过程以及彼此转换中被理解为不同的 moments。

于是序列并不是简单的单向 A—B—C，因为 C 会反过来改变我们对于 A 和 B 的理解。这意味着空间经验具有一种回溯性。所谓“到达”，不只是抵达一个新的空间，也是在重新解释刚才经过的路径。

4. 延迟：真正被设计的是空间何时出现

由此又能够进一步理解 Moretti 对圣彼得大教堂的分析。如果巨大空间在入口处一次性被完全给予，那么它仍然可以拥有巨大的绝对体积，但其序列力量会显著减弱。

这里真正重要的是：“巨大”何时出现。

圣彼得的进入过程中，门槛、墙体、门廊、长轴、转折和连续空间不断控制目标何时被完整给予。因此，差异会进一步产生延迟。差异首先意味着前一个空间与后一个空间不同，延迟则意味着：后一个空间尚未完全到来。

从这里便可以得到一条更完整的空间链：差异—延迟—期待—到达—新差异。

空间总是会先给身体一小部分暗示：一束光、一截穹顶、远端的一处亮面、一条被部分遮挡的轴线。身体知道“那里还有什么”，却暂时无法完整占有它。因此，最强的空间期待并不来自完全不知道目标，而来自：已经感知到它，却还没有抵达它。

这里的期待和前文中的空间回溯使序列开始拥有真正的时间厚度。空间经验不再只有“现在在哪里”，而同时包含刚才经历了什么，以及接下来可能发生什么。

（两个时间：身体向前，历史向后）

圣彼得大教堂还有一个更特殊的层面。建筑自身经过多个历史阶段才最终形成，而今天的人从广场进入大殿时，却沿着与建筑生成历史不同的顺序方向穿越这些空间层次。

于是同一座建筑中出现两个时间：一个是建筑被建造出来的历史时间，另一个是身体正在穿越建筑的经验时间。它们未必同向。

因此，建筑空间不再只是几何结构被身体依次读取的问题。历史也进入序列。一个当下的行动可以穿越多个历史时期留下的空间关系，而这些不同历史层次，在一次连续行走中被重新组织为当前经验。

身体在物理意义上不断向前，但在建筑历史意义上，它却可能不断向过去深入。这说明 sequence 最终不是简单的空间排列，而是一种时间结构。

五、Moretti 方法的限度：抽象以后，身体必须回来

为了看清空间结构，获得如此清晰的空间关系图，他必须把大量现实建筑空间中的因素暂时删除：材料、结构构件、家具、声音、人群、温度、触感、使用方式等，都可能在空间模型中消失。

可是当空间分析进入他提出的四个重要属性中的后两个：density 与 pressure 时，这些被删除的东西又不得不回来。

因为，没有实体边界，就难以谈压力；没有开口与材料，就难以谈光；没有身体，就不存在真正意义上的逼近和释放。所以，Moretti 的分析方法内部形成了一个循环：建筑 → 抽象 → 纯空间 → 差异分析 → 压力与密度 → 身体重新进入 → 现实建筑重新出现。

这意味着空间模型不应该被误解成“建筑的本质”，它是一种分析装置。它暂时牺牲现实复杂性，以换取关系的清晰；而真正完整的分析，必须在得到这些关系之后，再重新把身体、物质和时间带回来。

六、从空间对象到空间事件

至此，可以把 Moretti 的研究重新划分成三个层面。

第一层是对象层：几何形式、尺度、体积，它回答“这个空间是什么”。

第二层是场层：光的分布、边界距离、压力、方向与身体可能的运动，它回答“这个空间怎样从背景中向身体显现”。

第三层才是序列层：相邻空间之间几何、体量、光和压力如何发生变化，它回答“这种关系怎样在身体运动中成为事件”。

所以一个建筑真正值得分析的，不只是空间的 Geometric Form、Volume、Density、Pressure，而是 ΔG、ΔV、ΔD、ΔP。因此，可以把 Moretti 的问题最终总结成一句话：

建筑并不是一组空间等待身体依次进入，而是一套差异关系借助身体的运动逐步成为现实。

也正因如此，设计建筑并不只是决定每个空间“是什么”，而是在决定：什么首先出现，什么随后改变，什么必须被延迟，什么只能在经过压缩之后展开，以及最终的到达如何反过来重新定义此前经过的一切。

简而言之，言而总之：

设计建筑是组织差异如何在身体的时间中发生。

这或许才是《Strutture e sequenze di spazi》最值得继续发展的理论内核：结构使空间彼此关联，序列使这些关系成为经验；而建筑发生在结构转化为序列的那一刻。
